This folder contains the generated output files produced by the AG2Vec processing pipeline.

The actual output files are **not stored in this GitHub repository** because they may be large.

## Instructions

1. Open the Google Drive link above.
2. Download the complete contents of the folder.
3. Extract the downloaded files if they are provided as a ZIP archive.
4. Copy all downloaded files directly into this folder:

```text
Ag2vec/data_output/
```
5. Make sure the folder structure matches the expected project structure before running the next stage.
Important
- Do not rename the downloaded files unless the code explicitly requires it.
- Do not place the files in another directory.
- The files in this folder are intentionally excluded from GitHub because of their size.
- Only this README.md is maintained in GitHub.
After downloading and copying the files, the AG2Vec output should be ready for the next stage of the pipeline.
